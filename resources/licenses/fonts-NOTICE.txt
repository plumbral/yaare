System fonts
The interface can use the platform UI font. The terminal's system monospace
option uses local Consolas on Windows, Menlo on macOS, or Linux monospace fonts.
The system fallback option delegates missing terminal characters to the platform.
System font files are not redistributed, installed, uploaded, or enumerated.
Only Inter, Google Sans Code and Maple Mono CN are bundled in this release.
