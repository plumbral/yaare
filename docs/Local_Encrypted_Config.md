# 本地加密备份与迁移

入口：**设置 → 同步与备份 → 本地加密备份**。

在不使用云存储或 Docker 自托管的情况下，可将配置导出为 `.yaare` 加密文件，用于本地备份或跨设备迁移。文件使用独立备份密码加密，支持跨系统（Windows / macOS / Linux）直接导入，不依赖原设备的系统钥匙串或本地数据库。

## 导出配置

1. 点击 **导出配置…**。
2. 输入并确认备份密码（至少 12 个字符）。
3. 点击 **选择位置并导出**，选择保存路径。中途取消或写入失败不会覆盖原有文件。

> 备份密码不会保存，遗失后无法从 `.yaare` 文件恢复。若原工作区仍可正常解锁，可重新导出一份备份。

### 本机数据库快照

Yaare 还会在数据目录的 `backups/` 中保存 SQLite 快照。工作区数据库容量上限为 1 GiB。常规快照有十分钟的间隔，间隔内保存的最后一次修改会在到期后补做快照。升级数据库结构前，Yaare 会先校验并保留一份旧版快照；如果升级中断，可以再次启动重试。

SQLite 快照保留已加密的凭据，但仍需原系统凭据或 Docker 实例密钥才能解密。主机地址、用户名、备注和快捷命令可以直接读取。跨设备迁移时，请使用带独立密码的 `.yaare` 导出文件。Docker 整个实例的备份与恢复步骤见 [Docker 部署指南](../deployment/docker/README.md#备份与恢复)。

## 导出范围

| 内容 | 是否导出 | 说明 |
| --- | --- | --- |
| 主机、分组、跳板、代理、端口转发规则 | 导出 | 保留完整连接配置 |
| 快捷命令 | 导出 | 保留全部快捷命令 |
| 连接与代理密码、身份、托管私钥及口令 | 导出 | 导入时由目标设备的系统凭据存储重新加密 |
| 语言、主题与终端显示偏好 | 导出 | 未自定义项按默认值处理 |
| 外部私钥文件 | 不导出 | 不包含文件内容及原绝对路径，迁移后需重新选择文件 |
| 本机字体、快捷键、连接与传输偏好、同步服务凭据 | 不导出 | 仅保留在当前设备 |
| 主机指纹信任、日志、传输进度、未保存内容 | 不导出 | 不参与迁移 |

> 若导入的是**不包含认证信息**的备份文件，本机已有身份与密钥会保持不变，但导入的主机不会自动关联它们，连接时需手动重新选择身份或认证。

## 导入与恢复

1. 点击 **导入配置…**，选择 `.yaare` 文件。
2. 输入该文件的备份密码，点击 **解锁并检查**。密码错误、文件损坏或版本不兼容时，不会修改现有配置。
3. 预览差异：查看主机、分组、命令、身份、密钥的数量变化，以及具体新增、移除或修改的主机。
4. 核对无误后点击 **确认导入并替换**。若预览期间本地配置发生变化，需重新检查。

### 原工作区的凭据无法解锁

先检查原系统账户和钥匙串是否已解锁。若密钥仍然缺失，桌面端在同一个导入窗口提供 **恢复到新工作区**。选择备份并输入密码，然后点击该按钮，选择新工作区的保存位置。Yaare 会在此位置创建独立的 `Yaare-Recovery-…` 目录，用当前账户的凭据存储重新加密备份中的凭据，并打开新窗口。原工作区和现有连接保留，可在找回旧钥匙串后继续使用。

请记下恢复完成时显示的数据目录。以后打开这个工作区时，给 Yaare 的启动命令添加 `--yaare-data-dir="<恢复目录的绝对路径>"`。Docker 用户可在使用新数据卷和密钥卷初始化的实例中导入同一份备份。

导入注意事项：

- **导入前自动备份当前配置**：确认替换前，Yaare 会将当前配置加密保存至 `<数据目录>/portable-backups/before-import-<标识>.yaare`，加密密码与本次解锁导入文件时输入的密码一致。导入后也可点击 **另存导入前备份…** 将副本保存到指定位置，后续可通过常规导入流程恢复。
- **自动暂停云同步**：导入后会自动暂停已配置的后台同步与备份（保留原有云存储设置），避免新导入的配置被云端覆盖。确认无误后再手动恢复同步。
- **已有连接保持不变**：当前已连接的 SSH 会话不受影响，不会自动重连。
- **新设备需重新核对指纹**：服务器指纹信任不随备份迁移，在新设备首次连接时仍需确认指纹。

## 格式与限制

- 新导出文件使用 `YAARE2` 的 profile 2。每次导出生成随机盐和 nonce，使用 Argon2id（64 MiB、3 次迭代、并行度 2）派生密钥，以 AES-256-GCM 加密，文件按 4 KiB 对齐。备份的用途参与认证，可在磁盘上移动或改名后导入。
- 新版可导入旧版 profile 1 的 `.yaare` 文件。在另一台设备上导入新备份前，请先将目标客户端升级到支持 profile 2 的版本。
- 配置正文上限 20 MiB，加密后的 `.yaare` 文件上限 24 MiB；备份密码至少 12 个字符，最长 1 KiB（UTF-8）。
- 如需多设备自动同步，请参阅 [配置同步与备份](Sync_and_Backup.md)。
