## SSH 登录与会话

- SSH 连接现在使用服务器的原生登录 Shell，恢复显示认证横幅、系统欢迎信息和上次登录记录（由服务器配置决定）。
- 终端和 SFTP 面板统一显示连接、认证和重连状态。断开连接后仍可滚动、搜索和复制已有的终端输出。
- 展开的会话侧栏可直接从对应标签或分组旁的「+」新建终端。

## 终端与文件

- 终端会识别输出中的 HTTP 和 HTTPS 网址。按住 Ctrl 单击即可在浏览器中打开，macOS 使用 ⌘ 单击。
- 修复终端在切换渲染器或调整显示缩放后右侧出现大块空白的问题，跨行选区会随终端列宽正确显示。
- 需要从 SFTP 切换终端目录或从菜单启动 ZMODEM 上传时，可在空白 Bash 提示符处为本次会话启用集成。Linux OpenSSH 用户也可在「Bash 终端集成」中预览并确认安装或移除当前远程账户的自动加载配置。
- 改进 ZMODEM 批量接收的结束确认。文件已保存但尚未确认整批结束时，终端会明确显示已保存的文件数。
