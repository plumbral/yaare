## 安装包
- Windows 提供 x64 和 ARM64 安装程序；Linux 提供 x86-64 和 ARM64 的 DEB、RPM 和 tar.gz。
- macOS 提供通用 DMG 安装包，支持 Apple 芯片和 Intel（要求 macOS 13.3 及以上），已在 M1 上验证启动、重开、钥匙串以及 SSH、SFTP 和 SCP。

## 终端与文件
- 支持管理主机、分组、身份和密钥，主机列表可选系统图标、云厂商图标或自定义图标，也支持跳板机、代理和端口转发。
- 终端支持多标签、分屏、自动重连和快捷命令（命令末尾带换行会自动执行）。
- 支持 SFTP 上传下载、传输队列和远程文本编辑；Windows 双栏目录比较遇到仅大小写不同的同名目录时，会连同子项一并标为冲突，自动同步会自动跳过。

## 配置同步
- 桌面端与浏览器版可通过 Yaare 自托管实例同步配置，也支持 WebDAV、S3 以及本地加密导出、差异预览和恢复。
