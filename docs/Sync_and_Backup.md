# 配置同步与备份

入口：**设置 → 同步与备份**。

支持将主机、身份、密钥、快捷命令及外观偏好加密同步至多台设备，并自动保留历史版本以供回滚。

## 支持的存储

| 存储类型 | 所需参数 | 说明 |
| --- | --- | --- |
| **Yaare 自托管** | 服务地址、设备令牌 | 浏览器版与桌面端互通，配对步骤见 [Docker 部署指南](../deployment/docker/README.md) |
| **WebDAV** | 服务地址、用户名、访问密码、独立目录 | 服务端根目录需预先存在，Yaare 仅创建指定的子目录 |
| **S3 兼容存储** | Endpoint、存储桶、区域、Access Key ID、Secret Key、对象前缀 | 存储桶需预先创建 |

保存配置时，Yaare 会自动检测存储能力：支持条件写入的存储会自动启用双向同步；不支持条件写入的存储降级为**仅自动备份**，避免并发覆盖；不满足基本备份条件的存储会直接报错。远程 HTTP 存储必须使用 HTTPS（本机回环测试允许使用 HTTP）。

## 配置与使用

1. 点击 **选择存储…**（修改配置时为 **配置…**），选择存储类型并填写连接信息。
2. 设置至少 12 个字符的**配置加密密码**。所有同步设备需使用相同的加密密码和目录/前缀。该密码与存储服务的访问凭据相互独立；后续修改其他项时留空将保留原密码。
3. 点击 **保存**，校验通过后自动启用后台同步或备份。
4. 首次同步或出现冲突时，点击 **检查与合并…**：互不冲突的修改会自动合并；同一条目在两端同时变更（或一端删除、另一端修改）时，需逐项选择保留的版本。

## 同步范围

- **参与同步**：主机（含自定义图标、跳板、代理、转发规则和超时）、分组、快捷命令；已保存的连接与代理密码、身份、托管私钥及口令（普通连接中选择的私钥文件，保存时会自动加密导入密钥库）；可携带偏好（语言、主题配色、终端配色、字号、行高、回滚行数、光标等，按项合并）。
- **仅保留在本机**：外部私钥文件及其本地路径、自定义快捷键、本机字体、连接与传输偏好、同步服务凭据、主机指纹信任、运行中的会话。

> 外观与本机偏好均保存在本地 SQLite 中，清理 WebView 缓存不会导致偏好丢失。

## 后台运行

配置完成后，可通过侧栏的 **同步与备份** 图标查看当前状态与历史记录，关闭弹层不影响后台任务执行。

- 应用运行期间每分钟检查一次，遇到临时网络异常会逐步退避重试；连续失败或出现冲突会在设置页提示。
- 当其他设备更新了远端版本时，下次检查会自动拉取并合并。
- 如果本机用来比较变更的同步基线丢失或损坏，Yaare 会暂停后台任务。仍可查看远端历史、修改同步设置和手动备份。点击 **检查与合并…** 核对本机与远端的差异，确认合并后，再点击 **继续后台任务**。
- 若上传中途断网或应用异常退出，下次启动时会先核对远端实际版本，再合并本地修改，避免静默覆盖。
- 桌面客户端关闭后不会残留后台常驻进程。

## 历史备份与恢复

- 每次同步发布都会自动保存一份历史版本（仅备份模式下会在检测到配置变化时生成），也可点击 **立即备份** 手动创建。
- 历史版本保留最近 **30 天**、最多 **120 个**（至少保留最新一份）。自动清理仅作用于 Yaare 生成的历史对象。
- 点击 **恢复备份…** 可按时间倒序查看历史版本，选择后先点击 **检查…** 预览增删改，再点击 **确认恢复并暂停同步**。
- 恢复前，Yaare 会在本机数据目录的 `portable-backups/` 下自动保存一份当前配置的完整加密副本（`restore-sync-*.yaare`，使用当前配置加密密码加密），后续可通过 [本地加密备份](Local_Encrypted_Config.md) 的导入功能找回。
- 恢复完成后会自动暂停后台同步与备份，已有 SSH 会话不受影响。核对无误后，点击 **继续后台任务** 或手动 **检查与合并…** 即可恢复同步。

## 安全与技术说明

- 同步范围内的配置先在本机压缩、填充和加密，再上传到 `current.yaaresync` 与 `backups/*.yaaresync`。新写入的 `YAARE2` 对象采用 profile 2，以 Argon2id（64 MiB、3 次迭代、并行度 2）派生 AES-256-GCM 密钥。同一次发布的对象可共用一次密码派生，每个对象使用独立的随机 nonce。
- 新对象按 4 KiB 对齐。存储服务仍可看到对象名称、备份时间和填充后的大小。客户端解密时验证对象在同步目录内的相对名称，恢复历史版本时还会核对文件名与正文中的创建时间。请保留新格式历史对象在 `backups/` 下的原名。
- 新版可读取旧版 profile 1 对象。旧备份的文件名和正文时间原本分别生成，恢复预览允许两者相差最多 5 分钟。请在新客户端首次写入前升级所有参与同步的客户端。使用 Yaare 自托管时，先升级服务端镜像。WebDAV 和 S3 按普通二进制对象存储，无需为此更新服务端。
- 桌面端使用当前用户的系统凭据机制保护已保存的同步密码与存储访问凭据。Docker 浏览器版在服务端使用实例密钥加密保存这些凭据。
- 忘记配置加密密码后无法从云端找回。
- 双向同步对存储的要求：WebDAV 需支持强 ETag、条件写入、独占 LOCK 和 MOVE；S3 需支持原子条件 PUT。
- 若远端格式版本高于当前客户端且不兼容，Yaare 会提示格式不兼容并保留本机现有配置。
- 如果不使用云存储，也可以通过 [本地加密备份](Local_Encrypted_Config.md) 手动导出与迁移。
